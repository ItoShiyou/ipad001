# 最終決定 — 何を作るか

決定日: 2026-09-03 / 状態: **確定（依頼者の指示により、一次データ取得を待たずに確定）**

---

## 決定

> ## 電子楽譜リーダー（iPad優先・買い切り・完全オフライン）
>
> **製品の約束: 「本番で絶対に落ちない譜面台」**

---

## なぜこれか

### 選定基準を差し替えた

2ラウンドの調査で、依頼時の基準「評価3.5前後のアプリ」が**目的に対して有害**であることが分かった。
3.5に沈むアプリは次のどちらかに偏る。

- **(a) 市場が小さすぎて回復体力がない** → 作り直しても天井が低い
- **(b) カテゴリ自体が技術的に難しく、誰も上手くできていない** → 私が作っても同じ壁に当たる

唯一実数値が取れた INKredible（Google Play 3.34 / 約25,000件）は (b) の典型で、
相手は GoodNotes 4.8 / 12.8万件。しかも勝負どころが Apple Pencil の低遅延描画と
パームリジェクションという、**個人開発が最も不利な一点**である。採用しない。

代わりに、以下の3条件を選定基準として採用する。

| 基準 | 理由 |
|---|---|
| **支払い意思が実証済み** | スポーツ動画分析を落とした理由がこれ。無料勢がいると買い切りは成立しない |
| **決定的な無料競合が不在** | 同上 |
| **既存勢の弱点が「機能不足」ではなく「信頼性」** | 機能は資本で殴られるが、**信頼性は丁寧さで抜ける**。個人開発の唯一の勝ち筋 |

### 電子楽譜がこの3条件を満たす

| 条件 | 評価 |
|---|---|
| 支払い意思 | ✅ **forScore が評価4.7・有料で15年続いている**。musicians が譜面ツールに金を払うことは証明済み |
| 無料競合 | ✅ **決定版の無料アプリが存在しない**。純正ファイルアプリでは譜めくりも演奏用途も成立しない |
| 既存勢の弱点 | ✅ 日本の実質寡占である **Piascore に「本番中にフリーズして完全応答不能」「メトロノームとチューナーが同時使用不可」「Dropboxから開くと既存楽譜が上書きされる」** という報告。**すべて信頼性の問題** |

### 依頼者の要件との適合

| 要件 | 適合度 |
|---|---|
| iPad優先 | ✅ **選択ではなく必然。iPad が譜面台そのもの。** iPhoneは実用にならず、iPad版が主でiPhone版が従、という構成が自然に正当化される |
| ローカル完結・サーバーなし | ✅ **必然。** ステージ上でネットワークに依存する譜面表示はあり得ない。「通信しない」が欠点ではなく**製品の中核的価値**になる |
| 定期更新のみ | ✅ バックエンド運用ゼロ |
| 買い切り | ✅ forScore が価格帯を作っている |
| 個人が実装可能 | ✅ PDFKit / PencilKit / AVAudioEngine / BLE-HID。**MLも動画パイプラインもサーバーも不要** |
| 日本市場 | ✅ 日本のタブレット市場で iPad **75.64%**。Piascore が日本語圏の incumbent |

### 決め手 — コンテンツのライセンスが不要

再調査で挙がった対抗候補「オフライン地図」は、**地図タイルの調達とライセンス**という
重い前提条件を抱えていた（国土地理院タイルの大量DL・再配布制約など）。
電子楽譜は **ユーザーが自分のPDFを持ち込む**ため、**コンテンツの権利処理が一切発生しない。**
サーバーを持たない方針と完全に整合する。これが最終的な決め手。

## v1.0 のスコープ

**中核価値は「速さ」と「落ちないこと」の一点に集中する。機能数では戦わない。**

### 入れるもの

1. **取り込み** — Files / AirDrop / Split View からのドラッグ&ドロップ。PDF と画像。全て端末内保管
2. **描画の先読み** — 次ページ（と前ページ）を常に事前レンダリング。**譜めくりで絶対に待たせない**
3. **譜めくり** — タップ / スワイプ / **BLEフットペダル**（AirTurn・PageFlip 等の HIDキーボードエミュレーション）
4. **セットリスト** — 曲順、リピート、曲間ジャンプ
5. **表示** — 見開き2ページ / 半ページめくり / 縦横 / 余白の自動トリミング / 暗所用の反転表示
6. **注釈** — PencilKit。指使い・練習記号。**元PDFは非破壊**、注釈は別レイヤで保持
7. **メトロノーム + チューナー** — **同時使用可能**（Piascore の明確な不満点をそのまま潰す）
8. **ブックマーク / リピート記号ジャンプ**
9. **バックアップ** — ユーザー自身の iCloud Drive / Files へ書き出し。**自前サーバーは持たない**

### 入れないもの（v1では明確に捨てる）

クラウド共有 / コミュニティ / 楽譜販売 / OMR（楽譜画像認識）/ 音響追従の自動譜めくり /
アカウント登録。**いずれも v1 の「落ちない」という約束を薄める。**

### 品質の作り込み（ここが製品そのもの）

- 起動から譜面表示までの時間、譜めくりのフレーム落ち、演奏中のメモリ圧を**計測して回帰させない**
- 演奏中はバックグラウンド処理を一切走らせない（サムネイル生成・インデックス作成は演奏外でのみ）
- **クラッシュゼロを最優先KPIに置く。** 「本番で落ちない」が唯一の宣伝文句だから

## 価格

| 項目 | 決定 |
|---|---|
| 無料枠 | **3冊まで全機能**（機能制限ではなく点数制限。Amazing Slow Downer Lite が「曲の1/4しか再生できない」制限で 2.7 に沈んだ失敗を踏まえる） |
| 買い切り | **¥2,500**（非消費型IAPで全解放） |
| 対象 | Universal Purchase（iPhone / iPad / のちに Mac） |
| 禁止事項 | **買い切りで売った機能を、後からサブスク側へ移さない。** Notability・PDF Expert・GoodReader・Teleprompter Pro のすべてがこれで信頼を失っている |

価格の根拠: forScore が上限（約$25）、Piascore の ¥500 が下限のアンカー。
その間で「forScore より安く、Piascore より本気」という位置に置く。

## 収益の見立て（予測ではなく感度分析）

**有料アプリのCVRには公開データが存在しない**（検証済み）。したがって販売本数は予測できない。
以下は「これだけ売れたらこうなる」という感度分析としてのみ読むこと。

| 前提 | 値 |
|---|---|
| 手数料 | 15%（Small Business Program、有料アプリにも適用されることを Apple 公式で確認済み） |
| 固定費 | 年 約¥17,000（Apple $99/年 + Google Play $25 一時金） |
| **損益分岐点** | **年 7本** |

| 月間販売本数 | 月商（手数料後） | 初年度累計（立ち上がり7.5ヶ月換算） |
|---|---|---|
| 20本 | ¥42,500 | ¥319,000 |
| 100本 | ¥212,500 | ¥1,594,000 |
| 400本 | ¥850,000 | ¥6,375,000 |

**この表のどの行になるかは、現時点では誰にも分からない。**
確実なのは損益分岐点が年7本であり、**外れても失うものがほぼ無い**という一点。

## この決定が覆る条件

**確定させたが、一次データで以下が判明した場合は再考する。**

```bash
python3 tools/appstore_probe.py search Piascore forScore
python3 tools/appstore_probe.py discover --country jp
```

| 判明した場合 | 判断 |
|---|---|
| Piascore が **4.6以上** で、直近更新がフリーズ問題を解消している | **再考。** 弱点が塞がれているなら参入余地が薄い |
| 日本ストアで forScore が既に強い地位を築いている | **価格を再検討**（¥1,800程度まで下げる） |
| `discover` が、この3条件をより良く満たす別カテゴリを出した | **その候補と比較して再判断** |
| 上記いずれでもない | **このまま P1 に着手** |

## 却下した候補と理由（最終）

| 候補 | 却下理由 |
|---|---|
| 手書きノート（INKredible対抗） | 唯一の実数値（3.34）はあるが、相手が GoodNotes 4.8 / 12.8万件。勝負どころ（Pencil低遅延・パームリジェクション）が個人開発の最弱点 |
| 音楽練習プレイヤー（スロー再生） | **初回の第1候補。撤回。** Anytune 4.8（Split View対応済み）・Capo 4.7 でカテゴリは十分に満たされている |
| スポーツ動画分析 | 市場の空白と2026年度の政策追い風は本物だが、**主要競合が無料**（Coachly、AIスマートコーチ、VisualEyes無料枠）。買い切りで戦う土俵ではない |
| テレプロンプター | Teleprompter Pro 4.75 / 15万件が支配。付け入る隙が小さい |
| PDF編集・書類管理 | GoodReader 4.66 / 約14,000件。実装量も最大 |
| オフライン地図・GPS | サーバーレスとの相性は最高だが、**地図データのライセンスという重い前提条件**。コンテンツ権利が不要な電子楽譜に劣る |
